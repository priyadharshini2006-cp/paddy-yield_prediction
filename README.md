# Paddy Yield Prediction (Streamlit)

Files: `app.py` (app), `yield_model.pkl` (trained model), `model_meta.json` (feature info),
`paddydataset.csv` (data), `train.py` (retrain: `python train.py .`).

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`

Deploy: push this folder to GitHub, then share.streamlit.io -> New app -> select repo -> main file `app.py`.
